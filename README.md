# Aportación de Jeronimo Javier

Esta rama de revisión recoge la aportación de Jeronimo Javier al desarrollo y comparación de modelos de predicción de cancelaciones hoteleras.

## Contenido

- Notebooks de modelos: árbol de decisión, Random Forest, red neuronal, XGBoost y regresión lineal.
- Notebook de comparativa: `notebooks/comparativa_modelos.ipynb`.
- Notebooks de análisis exploratorio de apoyo.

## Artefactos de modelo

Los modelos serializados no se incluyen en Git. Deben generarse localmente al ejecutar los notebooks con los datos de la asignatura. Esta exclusión evita publicar artefactos binarios derivados de los datos y permite reproducir el proceso.

## Relación con la entrega

La solución técnica consolidada, el modelo seleccionado, las pruebas y la documentación final se revisan en la rama `cierrentrega/toni`. Esta rama permite identificar y revisar de forma independiente la contribución de Jeronimo Javier.
